# 🚀 Interview Journal

Welcome to my personal Interview Journal — a living knowledge base that documents my journey as a Backend Engineer.

This repository is more than a collection of interview questions. It is a place where I capture my interview 
experiences, technical learnings, backend concepts, and everything I study along the way. The goal is to continuously 
improve my understanding, identify knowledge gaps, and build a reference that I can revisit whenever needed.

## 🎯 Purpose

This repository helps me to:

- Document interview experiences from different companies.
- Record technical questions and discussions from interview rounds.
- Maintain structured notes on backend engineering concepts.
- Capture new topics and technologies as I learn them.
- Revisit concepts before future interviews.
- Track my growth as an engineer over time.
